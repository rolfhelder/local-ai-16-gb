# Topic template

Copy this layout into ignored `knowledge/<topic>/`.

- `brief.md`: question, current knowledge, scope, stopping rule.
- `sources/`: retrieved text/captions and metadata; respect source terms.
- `source-ledger.csv`: source_id,url,title,author,published,retrieved,status,language,evidence_location,limitations.
- `claims.md`: claim → source IDs/sections; contradictions and inferences.
- `checkpoint.md`: answered questions, current position, next batch.
- `synthesis.md`: evidence-backed explanation.
- `lesson.md`: prerequisites, concepts, worked example, exercise.
- `quiz.md`: questions and learner responses.
- `review-log.md`: misconceptions, corrections, next review suggestions.

Avoid committing private learning notes, copyrighted full-text collections, or session transcripts accidentally. The ignored folder is the default working library; this example contains no actual sources.
